About this preview

Uses an embedded 748-byte WebAssembly module, compiled from adapted C helpers in LASRecomp's runtime/cpu.h. The source is in this repository at arm64_flags.c.

Guest memory mapping, runtime dispatch, shaders and game assets are not ported yet. The production game at LAS Web Engine is unchanged.
