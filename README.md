# LAS Web Engine — Island Trial v0.2

A self-contained, original WebGL2 3D adventure proof-of-concept for Safari on iPhone 12 Pro Max and desktop browsers. **This is not Zelda, not an LAS Recomp port, and does not play Nintendo game files.** It tests the browser rendering, controls, basic physics/collision, collecting objectives, enemies, gamepad input, and FPS.

## Run on Windows 11

Open a PowerShell terminal in this folder:

```powershell
py -m http.server 8000
```

Then open `http://localhost:8000` in a Windows browser. You can also open `index.html` directly in many browsers, but using HTTP is recommended.

## Test on an iPhone

1. Publish the contents of this folder as a static site on **GitHub Pages** (Settings → Pages → Deploy from branch → main → root), or another HTTPS static host.
2. Open the resulting `https://...github.io/.../` URL in Safari.
3. Tap PLAY DEMO, and rotate the iPhone to landscape.
4. Optional: Safari Share → Add to Home Screen.

No Mac, app store, build process, CDN, dependencies, streaming server, or remote game host is required. The static host delivers the files; gameplay runs locally using WebGL2.

## Controls

- iPhone: joystick, A attack, B dash, pause.
- Desktop: WASD / arrows, Space attack, Shift dash.
- Standard gamepad: left stick move, button A attack, B dash.

## Performance improvements in v0.2

- Merged static ground tiles into one GPU mesh, replacing hundreds of per-frame terrain draw calls.
- Auto quality mode reduces internal pixel resolution when sustained FPS is low, and gently raises it when sustained performance improves.
- Cap pixel density for Safari; presets for Balanced, High, and Battery saver remain available.
- Reuse typed matrix buffers and reset touch/keyboard state after tab backgrounding.
- No new network requests, assets, dependencies or telemetry.

Performance improvement is expected but has not yet been benchmarked on an actual iPhone 12 Pro Max.

## Current limitations and next steps toward LAS Recomp

This demo does not include Nintendo game code or assets, a WebAssembly translation of LAS Recomp, Vulkan shader translation, Switch services, real LAS memory emulation, or a game asset importer. A full Link's Awakening (2019) browser version requires separate substantial engineering and validation of WASM memory constraints (especially on Safari), runtime, shader conversion and game-file loading. Distribution of any Nintendo assets or game code must be avoided; participants would have to legally supply their own data.

## Privacy

The demo doesn't upload files or send user data to a server. It doesn't use analytics, tracking, or external JavaScript.
